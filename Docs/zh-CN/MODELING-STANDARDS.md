# 建模标准：GB

[English](../MODELING-STANDARDS.md) | **简体中文**

本分支默认采用 **GB（中华人民共和国国家标准）** 作为建模与制图标准。ISO 作为
显式回退保留：当 GB 表尚未实现，或供应商明确要求 ISO 时使用。

本文说明项目**打算执行的标准**、**代码实际实现了什么**、**哪些仍需人工检查**。
它不是 GB 合规认证。

## 3. 如何使用 GB 默认

```python
# 默认就是 GB；结果的 hole["standard"] 为 "GB"
hole = add_hole_wizard("clearance", "M3", "+z", 20, 10, 10)

# 供应商要求 ISO 时显式回退
hole = add_hole_wizard("clearance", "M3", "+z", 20, 10, 10, standard="ISO")

# 带 GB 标题栏的图纸
make_drawing("bracket.pdf", template=r"C:\...\gb.drwdot")
```

SolidWorks 自带 GB 绘图模板（如 `gb.drwdot`）和 GB 图纸格式（如
`a4 - gb portrait.slddrt`）。安装路径因版本和语言而异，请显式传入模板路径，
不要在代码里写死安装目录。

## 4. “GB 默认”不意味着什么

- 不意味着生成的图纸已经是完整 GB 生产图。标题栏、公差、配合、粗糙度、几何
  公差仍需人工审核。
- 不意味着改变 SolidWorks 内部螺纹轮廓库。GB/T 192/196/197 与 ISO 68/724
  的基本牙型相同，公制代号（`M10x1.5`）也相同。
- 不意味着模型通过 GB/T 26099 认证。项目只实现可控部分（单位、全定义草图、
  特征命名、历史顺序、验证），其余明确列为人工项。
- 不改变 Y-up 零件模板要求。Y-up 是工具使用的 SolidWorks 建模坐标系，与图纸
  投影标准无关。

## 5. 变更策略

- `add_hole_wizard` 的 GB 默认是项目标准；改默认值属于破坏性变更，需要发布说明。
- ISO 是受支持的显式回退；移除前必须经过弃用周期。
- 新增标准表功能必须写明 GB 标准号、ISO 对应标准（如有），以及是自动还是人工。
- GB 与 ISO 数值不一致时，默认路径以 GB 表为准。
